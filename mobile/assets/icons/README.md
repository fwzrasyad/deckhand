# Icons

App icons, the adaptive-icon foreground, and the notification icon live here.

Nothing is checked in yet: Phase 0 ships the skeleton and the default launcher
icon generated by `flutter create`. Phase 3 adds:

- `app_icon.png` — 1024×1024 source for `flutter_launcher_icons`.
- `app_icon_foreground.png` — foreground layer for the Android adaptive icon.
- `notification_icon.png` — white-on-transparent monochrome icon, required by
  Android for alerts.

Assets are declared in `pubspec.yaml` once the first real file exists, because
Flutter fails the build when an asset directory in `pubspec.yaml` is empty.
